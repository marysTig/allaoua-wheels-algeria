# Allaoua Wheels

Crée un site web vitrine complet, moderne et responsive pour une agence de location de voitures en Algérie.

═══════════════════════════

INFORMATIONS DE L'AGENCE

═══════════════════════════

- Nom : ALLAOUA Location (Ets ACHOURI)

- Activité : Agence de location de voitures, avec ou sans chauffeur

- Adresse : Cité 50 logements, Seddouk 06011, Algérie (à 100m de la protection civile)

- Horaires : Ouvert 24h/24

- Téléphone / WhatsApp 1 (Allaoua) : 0770 64 65 57

- Téléphone / WhatsApp 2 (Idir) : 0540 84 58 43

- Localisation Google Maps : Plus Code GMWP+PM Seddouk

═══════════════════════════

STRUCTURE DU SITE

═══════════════════════════

1. HEADER

- Logo texte "ALLAOUA Location"

- Menu : Accueil, Véhicules, Services, Contact

- Bouton "Appeler maintenant" visible en permanence

- Bouton WhatsApp flottant fixe en bas à droite sur toutes les pages

2. HERO

- Titre : "Location de voitures à Seddouk, avec ou sans chauffeur"

- Sous-titre percutant sur la fiabilité et la disponibilité 24h/24

- Boutons d'action : "Appeler" / "WhatsApp" / "Voir les véhicules"

- Image de fond ou illustration de voiture

3. SECTION "NOS VÉHICULES"

Cartes véhicules avec pour chacune :

- Nom du véhicule (titre)

- Catégorie (badge : Minibus, Berline, Citadine, Utilitaire)

- Image (placeholder)

- Caractéristiques avec icônes :

  - Boîte : Manuelle

  - Carburant : Diesel

  - Places : 9 Sièges

  - Portes : 5 Portes

  - Kilométrage : Limité à 500 Km/jour (Illimité à partir de 6 jours)

- Prix par jour (placeholder "Prix sur demande")

- Bouton "Réserver" ouvrant WhatsApp avec message pré-rempli : "Bonjour, je souhaite réserver le véhicule [Nom du véhicule], merci de me donner plus d'informations."

Génère 6 cartes d'exemple avec noms de modèles réalistes (minibus/utilitaires diesel 9 places).

4. SECTION "NOS SERVICES"

Deux cartes avec icônes :

- Location avec chauffeur : "Un chauffeur expérimenté vous conduit où vous le souhaitez, en toute sécurité et sans souci de conduite."

- Location sans chauffeur : "Prenez le volant vous-même et profitez d'une totale liberté de déplacement, à votre rythme."

5. SECTION "POURQUOI NOUS CHOISIR"

4 points forts avec icônes : Prix compétitifs, Véhicules récents et entretenus, Service rapide, Disponibilité 24h/24

6. SECTION "CONTACT"

- Adresse complète

- Carte Google Maps intégrée (embed)

- Les deux numéros affichés et cliquables (lien tel:)

- Boutons WhatsApp séparés pour Allaoua et Idir

- Formulaire simple (nom, téléphone, dates souhaitées, message) qui envoie vers WhatsApp

7. FOOTER

- Coordonnées complètes

- Liens rapides vers les sections

- Mention "Ets ACHOURI - Seddouk"

═══════════════════════════

DESIGN

═══════════════════════════

- Palette : bleu marine et blanc avec accent orange

- Style moderne, épuré, mobile-first

- Cartes avec ombre légère et coins arrondis

- Grille responsive (3 colonnes desktop, 1 colonne mobile)

- Boutons d'appel/WhatsApp toujours accessibles

- Site entièrement en français
